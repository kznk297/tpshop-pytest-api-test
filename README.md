# TPshop 商城接口自动化测试

基于 TPshop 开源商城的 Python 接口自动化测试项目，覆盖登录、购物车、下单全链路，
并将实际发现的越权缺陷沉淀为回归用例。

## 技术栈

- Python 3.11
- pytest 9
- requests
- pytest-html

## 覆盖范围

| 模块 | 用例数 | 说明 |
| --- | --- | --- |
| 登录 | 3 | 正向登录、密码错误、账号为空 |
| 购物车 | 5 | 正常加购 + 数量 0/201、缺商品 ID、缺规格 |
| 下单链路 | 1 | 加购 → 查购物车 → 提取地址 → 提交订单 |
| 安全回归 | 1 | 他人收货地址越权下单（已知缺陷） |

当前结果：**9 passed, 1 xfailed**
